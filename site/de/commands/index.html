Welcher Befehl hilft mir gerade?

Such dir aus, was du tun willst. Jeder Befehl unten sagt, wann du ihn nutzt, was du bekommst, wie du ihn tippst und was danach passiert.

Befehle zeigen für

Ich will …

  • Eine Idee klären/brainstorm, /grill, /deepen
  • Ein Projekt starten/bootstrap, /plan new
  • Eine Funktion planen/plan feature
  • Bauen/session, /go, /close
  • Pflegen/session housekeeping
  • Untersuchen/discovery, /debug
  • Testen/test, /ux-grill
  • Zurückschauen/eval, /plan retro
  • Lernen/evolve, /reconcile
  • Viele Repositories führen/portfolio, /dispatcher

Faustregel

Welche Session du startest
Weißt du genau, was du bauen willst?/session feature
Noch unsicher, was du bauen willst?Erst /plan feature
Große oder unklare Änderung?/session deep
Aufräumen?/session housekeeping

So tippst du einen Befehl in deinem Coding-Tool

Wie jedes Coding-Tool einen Befehl ausführt
Claude CodeTippe /name in den Chat. Im Headless-Modus claude -p brauchen nur /session und /plan die lange Form, zum Beispiel /session-orchestrator:session deep.
Codex CLIWähle den Skill im Codex-Chat: $session-orchestrator:name. Es ist kein Shell-Befehl. Das einfache /go und /close funktioniert dort nicht, und Codex startet go oder close nie von selbst.
Cursor IDETippe /name. Die Agents arbeiten nacheinander.
PiTippe /name. Jeder Befehl ist eine Prompt-Vorlage.

31 von 31 Befehlen

Kein Befehl passt. Leere das Feld, um alle 31 zu sehen.

Hier anfangen

Sechs Befehle reichen für deine ersten Sessions. Lerne diese und lass den Rest liegen, bis du ihn brauchst.

Du bekommst
Eine CLAUDE.md (auf Codex und Pi AGENTS.md) mit einer Session Config und der Mindeststruktur für das Repository, committet. Du siehst die angelegten Dateien und den Commit-Hash.
Eingabe
Claude Code

Codex
$session-orchestrator:bootstrap
Cursor
/bootstrap
Pi
/bootstrap
Wirkung
Committet fragt vorher 7 bis 9 Fragen zur Einrichtung; /bootstrap --fast --no-interview überspringt sie und nimmt sinnvolle Standardwerte
Braucht
Ein Git-Repository.
Danach
Starte mit /session feature deine erste Session.

/session Hier anfangen

Wann
Du setzt dich an die Arbeit in einem Repository und willst wissen, was als Nächstes dran ist.
Du bekommst
Es liest dein Repository (Git-Stand, Issues, CI, Umgebung) und schlägt vor, woran du arbeitest. Nichts ändert sich, bis du zustimmst.
Modi

  • feature eine klare Funktion bauen (am besten für die erste Session)
  • deep große oder unklare Änderung: erst untersuchen, dann bauen (der Standard)
  • ultradeep ein optionales, längeres Profil von deep für eine benannte Forschungsfrage; kein vierter Typ

Claude Code

Codex

Cursor

Pi
/session
Wirkung

Braucht

Danach
Stimme dem Plan mit /go zu.

/plan Hier anfangen

Wann
Du willst ein neues Projekt oder eine Funktion planen, oder auf eine abgeschlossene Phase zurückschauen.
Du bekommst
Eine recherchierte Fragerunde, danach ein PRD oder ein Retro-Dokument und priorisierte Issues.
Modi
  • new ein neues Projekt: legt auch das Repository an und committet
  • feature eine Funktion: PRD und Issues
  • retro auf eine abgeschlossene Phase zurückschauen
Eingabe
Claude Code
/plan [new|feature|retro]
Codex
$session-orchestrator:plan feature
Cursor
/plan feature
Pi
/plan
Wirkung
Öffnet Issues fragt vorher schreibt das PRD oder die Retro; new legt auch ein Repository an und committet
Braucht
/bootstrap ist erledigt. /plan new nutzt plan-baseline-path, wenn gesetzt, sonst die mitgelieferten Vorlagen; feature und retro brauchen es nie.
Welcher
Nur eine Idee: /brainstorm. Umfang bekannt: /plan feature. Ganz klar: /session feature. Das PRD landet standardmäßig in docs/prd/ (plan-prd-location).
Beispiel
Tippe /plan feature. Beantworte die erste Frage (was gebaut werden soll) mit deiner Aufgabe, zum Beispiel „Füge der Rechnungsliste einen CSV-Export hinzu“. Das PRD wird nach docs/prd/YYYY-MM-DD-<feature-name>.md geschrieben.
Danach
Wenn du willst, prüfe das PRD mit /grill, dann baust du es mit /session feature.

Wann

Du bekommst
Die Release-Schritte in der vorgeschriebenen Reihenfolge, mit den Bedingungen, die ein Release stoppen.
Eingabe
Claude Code

Codex

/release
Pi
/release
