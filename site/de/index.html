Du tippst drei Befehle entlang einer Linie. /session: Du sagst, was du willst, und der Plan ist erst eine gestrichelte Linie. /go: Es setzt erst nach deinem Ja um; ab dann ist die Linie durchgezogen. Es arbeitet in Runden, drei für ein Feature, geprüft mit deinen Tests. /close: Es hält fest, was für das nächste Mal erledigt ist.

In dem Tool, das du schon nutzt.

Dieselben drei Schritte in jedem Tool; in Codex sind es Skills. Claude Code und Codex führen Agents nebeneinander aus, Cursor und Pi nacheinander.

Du brauchst Node.js 24 oder neuer und ein Git-Repository.

Claude Code

Tippe diese beiden Zeilen in den Claude-Code-Chat, nacheinander.

/plugin marketplace add Kanevry/session-orchestrator
/plugin install session-orchestrator@kanevry

Einmal pro Projekt: /bootstrap --fast --no-interview. Danach gibt dir /session einen Plan, und dein Code bleibt unverändert, bis du mit /go antwortest.

Codex

Einmal im Terminal. Braucht Codex CLI 0.160 oder neuer.

git clone https://github.com/Kanevry/session-orchestrator.git ~/Projects/session-orchestrator
cd ~/Projects/session-orchestrator && npm install && node scripts/codex-install.mjs

Starte danach eine neue Codex-Aufgabe, tippe /hooks und gib die Hooks von Session Orchestrator frei. Einmal pro Projekt: $session-orchestrator:bootstrap --fast --no-interview.

Im Codex-Chat, in der App oder der CLI, sind die Befehle Skills: $session-orchestrator:session, $session-orchestrator:go, $session-orchestrator:close.

Cursor

Einmal im Terminal:

git clone https://github.com/Kanevry/session-orchestrator.git
cd session-orchestrator && npm install
node scripts/cursor-install.mjs /absolute/path/to/your/project

Danach einmal /bootstrap und dann /session im Cursor-Chat.

Pi

Einmal im Terminal:

npm install -g --ignore-scripts @earendil-works/pi-coding-agent
pi install npm:session-orchestrator

Danach einmal /bootstrap und dann /session in Pi.
