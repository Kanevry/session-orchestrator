European Digital Innovation Hubs · KMU

Eine erste Coding-Sitzung mit Prüfungen an einem Nachmittag.

Session Orchestrator ist ein freies Werkzeug für Softwareteams, die mit KI-Coding-Agenten arbeiten. Sie stimmen einen Plan ab, prüfen die Änderungen mit den eigenen Projektbefehlen und halten die Übergabe schriftlich fest.

0 EUR. Das Werkzeug steht unter MIT-Lizenz. Session Orchestrator läuft lokal in Ihrem Git-Repository ohne eigenes Konto oder eigenen Server. Das Modell kommt vom Coding-Agenten. Dessen Anbieter kann eigene Kosten verrechnen.

Standardmäßig fragt das Plugin bei der npm-Registry nach Updates. Die Sicherheitsprüfung ruft die Versionsliste von Node.js und den CISA-KEV-Feed ab. Sie filtert private Pakete heraus, bevor sie Paketnamen und Versionen aus Ihrer Lockdatei an OSV sendet. Bei GitHub-Remotes fragt sie außerdem über gh private Schwachstellenmeldungen ab. Mit SO_DISABLE_UPDATE_CHECK=1 schalten Sie die Update-Prüfung ab, mit SO_SECURITY_PULSE_REFRESH=off die Sicherheitsprüfung. DO_NOT_TRACK=1 oder CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1 schalten beide Prüfungen ab. Telemetrie ist nur mit Zustimmung aktiv. Siehe Netzwerkverbindungen in der Anleitung (Englisch).

Jetzt ausprobieren

Von der Installation bis zur Übergabe

EDIH-Beratung und Entwicklung probieren den Ablauf gemeinsam aus. Sie brauchen Node.js 24 oder neuer, ein Git-Repository mit funktionierenden Prüfungen und eine kleine Änderung, die sich am selben Nachmittag begutachten lässt.

  1. Installieren Sie Session Orchestrator in Claude Code zuerst mit /plugin marketplace add Kanevry/session-orchestrator und dann mit /plugin install session-orchestrator@kanevry. Für Codex CLI, Cursor oder Pi folgen Sie der Installationsanleitung (Englisch) für Ihren Coding-Agenten.
  2. Öffnen Sie das Projekt im Coding-Agenten und richten Sie die Session Config mit /bootstrap ein. Tragen Sie unter test-command, typecheck-command und lint-command Ihre eigenen Prüfbefehle ein. In einem npm-Projekt können das npm test, npm run typecheck und npm run lint sein.
  3. Starten Sie mit /session feature und stimmen Sie den Plan ab. Starten Sie die erste Runde mit /go und prüfen Sie die Ergebnisse. Schließen Sie mit /close ab und lesen Sie gemeinsam die Übergabe. Die Anleitung (Englisch) zeigt die Aufrufe für die einzelnen Coding-Agenten.

Pi und Modellbetrieb

In Pi laufen Aufgaben nacheinander und der für das Modell bestimmte Hook-Kontext kommt nicht an. Ob Pi live mit dem Plugin funktioniert, ist noch in keinem aufgezeichneten Lauf belegt. Geplant ist je ein aufgezeichneter Durchlauf mit einem europäischen Modellanbieter und mit einem Modell auf eigener Hardware. Eine Variante gilt erst als geprüft, wenn ein aufgezeichneter Lauf die veröffentlichten Kriterien (Englisch) erfüllt.
