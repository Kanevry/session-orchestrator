Install the plugin

You type three commands along one line. /session: you say what you want, and the plan is only a dashed line. /go: nothing is built before your yes; from there the line is solid. It works in rounds, three for a feature, checked with your tests. /close: it notes what is done for next time.

Install in Claude Code, Codex CLI, Cursor or Pi.

The command reference shows how each tool runs a command.

You need Node.js 24 or later and a Git repository.

Claude Code

Type these two lines in the Claude Code chat, one after the other.

/plugin marketplace add Kanevry/session-orchestrator
/plugin install session-orchestrator@kanevry

Once per project: /bootstrap --fast --no-interview. Then /session gives you a plan, and nothing in your code changes until you answer /go.

Codex

In a terminal, once. Requires Codex CLI 0.160 or later.

git clone https://github.com/Kanevry/session-orchestrator.git ~/Projects/session-orchestrator
cd ~/Projects/session-orchestrator && npm install && node scripts/codex-install.mjs

Then start a fresh Codex task, type /hooks and approve the Session Orchestrator hooks. Once per project: $session-orchestrator:bootstrap --fast --no-interview.

In the Codex chat, in the app or the CLI, the commands are skills: $session-orchestrator:session, $session-orchestrator:go, $session-orchestrator:close.

Cursor

In a terminal, once:

git clone https://github.com/Kanevry/session-orchestrator.git
cd session-orchestrator && npm install
node scripts/cursor-install.mjs /absolute/path/to/your/project

Then /bootstrap once and /session in the Cursor chat.

Pi

In a terminal, once:

npm install -g --ignore-scripts @earendil-works/pi-coding-agent
pi install npm:session-orchestrator

Then /bootstrap once and /session in Pi.
