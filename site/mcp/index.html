Install

Docs server · MCP · read-only

Ask the docs from your own agent.

One URL, nothing to install. Add it to any agent that speaks MCP, then ask how to install Session Orchestrator, which skill fits a task, or what is wrong with your Session Config.

https://mcp.session-orchestrator.com/mcp

Streamable HTTP. No account, no sign-in. It answers from the documentation of the released version, currently v5.22.0.

Connect · The five tools · Try these · What it does not do · Privacy · Server or plugin

Connect

Add it to
your agent.

Pick your client. Claude Code and Codex CLI were tested with these commands. The other clients are described as their vendors document it; they were not tested here.

Claude Code

Tested on macOS.

claude mcp add --transport http session-orchestrator https://mcp.session-orchestrator.com/mcp

claude mcp list

claude mcp list then shows the server as connected. For a team, Claude Code’s documentation describes --scope project, which writes the server into .mcp.json in the project; not tested here.

Codex CLI

Tested on macOS and Linux.

codex mcp add session-orchestrator --url https://mcp.session-orchestrator.com/mcp

codex mcp list

According to OpenAI’s documentation, the ChatGPT desktop app and the Codex IDE extension read the same configuration; not tested here.

Cursor

From Cursor’s documentation, not tested here. Put this in .cursor/mcp.json:

{"mcpServers":{"session-orchestrator":{"url":"https://mcp.session-orchestrator.com/mcp"}}}

VS Code (Copilot)

From the VS Code documentation, not tested here. Put this in .vscode/mcp.json:

{"servers":{"session-orchestrator":{"type":"http","url":"https://mcp.session-orchestrator.com/mcp"}}}

Pi

From Pi’s documentation, not tested here.

pi mcp add session-orchestrator --url https://mcp.session-orchestrator.com/mcp

Claude desktop app and claude.ai

From Anthropic’s documentation, not tested here.

Open Customize › Connectors › Add custom connector. Enter a name and the URL above, and choose “No sign-in”. On Team and Enterprise plans, an owner adds it.

What it offers

Five tools,
all read-only.

Your agent picks the tool. You just ask your question.

The five tools of the docs server
searchSearches the public documentation of the released plugin version.
fetchReads one documentation section in full.
list_skillsFinds the skill that fits a task.
check_session_configChecks a pasted Session Config block for keys that have no effect, and names the key you probably meant.
get_release_notesShows the latest version and what changed.

Limits

What it
does not do.

It reads documentation. That is all.

  • It does not install the plugin and has no hooks.
  • It runs no command and changes nothing.
  • It cannot see your repository. It only checks the text you send to it.

The full plugin, with planning, waves, quality gates and close-out, is still installed as described on the home page.

Privacy

Nothing
to sign up for.

No account, no sign-in, no cookies.

  • The server stores no input and keeps no log of requests or IP addresses.
  • A Session Config block you ask it to check is sent to the server, checked in memory and not stored.
  • All five tools are marked read-only.
  • The plugin is open source under the MIT licence: source on GitHub.
