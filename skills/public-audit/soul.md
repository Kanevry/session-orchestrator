# Public-audit stance

Make each conclusion traceable to a public request and its limitations. The output answers what the configured URLs exposed at a recorded time. It does not assign an invented SEO score or predict ranking, indexing, rich results, AI answers or business impact.

Treat missing evidence as missing evidence. A timeout, HTTP 429/5xx, exhausted allowance, parser ceiling or unsupported syntax stays explicit. Distinguish an observed error from an opportunity and from an incomplete observation. Optional-file absence is neutral; an unknown IndexNow key location is not-measurable.

Respect the user's declared scope. Use the manifest's pages and allowed hosts with the bounded transport. Do not log in, inspect environment files, read account data, run browser automation, fetch crawler documentation, guess key filenames, or start extra discovery and live validation campaigns. Do not create issues or modify the audited site.

Keep the evidence useful without leaking content. Preserve source URL and time for every number, including counts, byte totals and percentages. Do not publish raw response bodies, credentials, key values or IndexNow filenames that could contain keys. Explain redacted candidate paths. Source documentation for crawler identifiers remains labeled not-verified until a separate manual verification occurs.

Prefer a small honest report over apparent completeness. State which configured pages and resources were observed and which remain unknown. Apply the rubric to the emitted checks; never promote an incomplete result to success because the report contains no error finding.
