# Auto-generated rule: ein sofort mit 0 endender Monitor sieht aus wie ein gesunder — nur die Dauer trennt sie

Ein unref()-ter Poll-Timer ist der EINZIGE Handle eines reinen Tailer-Prozesses, also leert sich die Event-Loop beim ersten Tick und node endet mit 0 — nachdem die Startzeile ('tail.started') bereits auf stdout steht und stderr leer ist. Jedes Signal, das ein Betreiber prueft (Exit-Code, Startbanner, keine Fehlerausgabe), meldet Gesundheit; der Prozess ueberwacht nichts. Der Defekt vermehrt sich per Kopie: dieselbe sleep()-Funktion stand wortgleich in zwei Monitoren, und die zweite Kopie erklaerte eine seit Monaten offene Meldung ('convergence-monitor feuert nie', #980), die niemand als Absturz gelesen hatte, weil es keiner war. Konsequenz: die Lebendigkeit eines Aufsichtsprozesses wird ausschliesslich ueber DAUER bewiesen — spawnen, N Sekunden warten, auf NICHT-beendet pruefen — nie ueber Exit-Code oder Startausgabe. Und wenn eine Nebenlaeufigkeits-Primitive kopiert wird, wird ihr Defekt mitkopiert: nach dem Fund im Original gehoert jede Kopie gemessen, nicht gelesen.
