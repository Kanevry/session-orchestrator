# Auto-generated rule: Ein Arbeitskopie-Artefakt (STATE.md, session.lock) ist kein prozesslokaler Identitaetszeuge — Zeugen stufen, nicht vereinigen

Wer die eigene Session-Identitaet aus STATE.md `session` oder aus session.lock ableitet, uebernimmt die Identitaet des Lock-Besitzers: beide Dateien schreibt die Session, die die Arbeitskopie besitzt. Eine Vereinigung (some()) von Zeugen unterschiedlicher Staerke laesst den schwaechsten gewinnen und kann von einer widersprechenden prozesslokalen ID nicht vetoiert werden. Regel (HR-102): nur ein prozesslokaler Zeuge (Hook-Payload session_id, CLAUDE_CODE_SESSION_ID) darf ein Lock bestaetigen; fehlt er, werden die Keys weggelassen, nie mit einem Peer-Wert gefuellt.
