# Auto-generated rule: ein dispatchter Subagent traegt die rohe Session-ID des Koordinators, nie eine eigene

CLAUDE_CODE_SESSION_ID in einem Subagenten-Prozess ist die ROHE UUID des Koordinators, der ihn gestartet hat — der Subagent bekommt nie eine eigene Session-ID. Jeder Mechanismus, der 'meine eigene Session-ID' braucht (Lock-Autorisierung, Scope-Zuordnung), muss das gegen eine PROZESSLOKALE Uebereinstimmung der rohen ID pruefen, nicht gegen eine angenommene Subagenten-Identitaet.
