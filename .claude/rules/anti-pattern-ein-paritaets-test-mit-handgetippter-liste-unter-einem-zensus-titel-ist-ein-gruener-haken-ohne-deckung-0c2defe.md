# Auto-generated rule: ein Paritaets-Test mit handgetippter Liste unter einem Zensus-Titel ist ein gruener Haken ohne Deckung

Ein Test, dessen Titel "matches every X the codebase emits" verspricht und dessen Subjekt ein handgepflegtes Array ist, prueft nur sich selbst. Er wird nie rot, wenn die Wirklichkeit davonlaeuft — und sein gruener Haken wird als Deckung gelesen, sodass der Naechste das Kaestchen abhakt. Das Rezept gehoert in Code (ein echter Zensus ueber die Quellverzeichnisse), nicht in eine Liste. Dazu zwei Waechter: ein Vakuum-Schutz (Zensus darf nicht leer sein) und eine Ratsche auf der Allowlist (etwas zu dokumentieren ERZWINGT das Streichen aus der Schuldenliste).

## Evidence
2026-08-23 in diesem Repo: tests/lib/events-schema.test.mjs pruefte gegen zehn Literale, waehrend 31 Ereignisnamen emittiert wurden — 21 ausserhalb, zehn davon ohne Katalog-Zeile. Der Test war seit Monaten gruen. Ersetzt durch einen Zensus + Katalog-Paritaet + Allowlist-Ratsche; falsifiziert, indem ein Allowlist-Eintrag dokumentiert wurde und der Test rot ging.
